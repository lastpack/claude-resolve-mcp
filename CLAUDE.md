# claude-resolve-mcp — editing in DaVinci Resolve with Claude (incl. the free version)

## How it works
- Free Resolve blocks external scripting (`scriptapp` -> nil), and 21.1+ has no in-app Python console either.
  So the bridge is **Lua**: `bridge/ResolveBridge.lua` runs INSIDE Resolve — Workspace > Console (Lua):
  `dofile([[<repo>/bridge/start.lua]])` (start.lua is generated by `install.ps1`), once per Resolve launch.
  Running it from Workspace > Scripts does NOT work (different environment, the bridge doesn't start).
- File protocol: `queue/req.lua` -> `queue/resp.json`; status in `queue/alive` ("running").
- `bridge/runtime.lua` and `bridge/helpers.lua` are re-read on every request — edit them without restarting the bridge.
- Run Lua: `uv run python tools/rl.py file.lua` (the code does `return ...`).
- The MCP server (`resolve_mcp/server.py`) is a thin wrapper: tools call Lua functions `mcp_*`/`fx_*` from
  `bridge/helpers.lua`. New capability = a function in helpers.lua + a tool in server.py.
- Agents (`.claude/agents`): footage-analyst (material -> plan), resolve-operator (executes the plan in Resolve,
  the only one that changes it), render-qc (checks the render). Order: analyze -> plan -> operate -> QC.
- Style (fonts, colors, pacing, look) always comes from the user's request or reference — the project has neutral defaults.

## Lua sandbox in Resolve 21
- No `io`, `os.remove/rename`, `debug`. Available: `loadfile`, `setfenv`, `ffi` (files are written via the CRT through ffi),
  `fileexists`, `wait(sec)`, `bmd`.
- Lists from the API are tables; get values with `vals()` from helpers.lua. They may contain a `__flags` key.

## Pitfalls (verified on Resolve 21.1 Free, Windows)
- **Fusion comps changed via the API don't render until the change goes through the undo system.**
  `activate(comp)` = StartUndo + add/delete a node + EndUndo(true). Called automatically in `fx_end`;
  call `activate_all(from, to)` before rendering. No clicking in the Fusion page needed.
- `AppendToTimeline`: `endFrame` is exclusive (length = endFrame - startFrame).
- After a Resolve restart the bridge is dead but `queue/alive` still says "running" — requests hang; restart the bridge.
- **Computer use: don't call open_application("DaVinci Resolve")** — the resolver may pick the wrong shortcut
  (it launched Blackmagic Proxy Generator). Bring the Resolve window forward via PowerShell
  (ShowWindow/SetForegroundWindow on the Resolve process MainWindowHandle).
- Audio: clip volume via the API is static only (`AudioVolume`, dB). Music ducking is mixed outside
  (`tools/mix_audio.py`, smooth ramps); voice — `tools/voice_fix.py` (channel -> centered mono, target LUFS, soft limit).
  Check with `tools/loud.py`. Never assume the channel layout: camera voice can be in one channel only; music is stereo,
  don't fold it to mono.
- Text/graphics: Remotion in `motion/` (KineticText.tsx, data in src/data/*.json, frames = timeline frames,
  composition fps = timeline fps), render ProRes 4444 with alpha -> import to the top track.
- ChannelBoolean in Fusion broke the render ("Fusion composition ... could not be processed") — RGB split uses
  two Transforms instead (`fx_rgb_split`).
- When deleting a node, reconnect the next node explicitly: `next:ConnectInput('Input', prev_tool)`.
- `item_at` skips titles (only clips with a MediaPoolItem).
- `AddModifier` puts a key at `comp.CurrentTime` — set the neutral "before effect" value as the first key
  (`{t0 - 1, 1.0}`); `keys()` handles this.
- `DeleteFusionCompByName` won't delete a clip's only comp — `clear_fx` deletes the nodes instead.
- Fusion Text+ fonts must be installed in the system; for Cyrillic etc. check the font supports it.
- Still images (PNG) are placed by `AppendToTimeline` for 5 s ignoring endFrame — make freezes as a short video.
- Changing timeline aspect: first `useCustomSettings=1`, then `timelineInputResMismatchBehavior=scaleToCrop`.
- Resolve can be memory-heavy — run Whisper/Remotion/x264 one at a time.
- Remotion: put temp frames on a disk with space (`TEMP`/`TMP`).
- `ExportCurrentFrameAsStill` is unreliable — verify with a render + `tools/grab.py`, `tools/stats.py`, `tools/qc_sheet.py`.
- libsndfile can't open non-ASCII paths — copy audio to `work/`.
- tools/ scripts with av/PIL/numpy: `uv run --no-project --with av --with pillow --with numpy python tools/...`.
